# GTR CF Test Origin

Cloudflare Worker fixture origin for `gtr-ext` integration and E2E tests.

It serves deterministic generated content with `HEAD`, `GET`, and single-range request support, plus small cookie/auth-protected endpoints that mimic the parts of Google Takeout behavior GTR needs to exercise.

## Commands

From the repo root:

```bash
npm run test-origin:test
npm run test-origin:typecheck
npm run test-origin:deploy -- --dry-run
npm run test-origin:deploy
```

Or from this folder:

```bash
pnpm test
pnpm typecheck
pnpm build
pnpm deploy
```

## Endpoints

- `/` - HTML index.
- `/setup.html` - Cookie setup page for manual browser testing.
- `/download/test.txt` - Requires `testcookie=valid`; redirects to `/setup.html` otherwise.
- `/download-no-cookie/test.txt` - Same deterministic text fixture without authentication.
- `/download-gtr-cookie-auth/test.txt` - Accepts `Cookie`, `GtrCookie`, or `Gtr2Cookie` payloads containing `testcookie=valid`.
- `/bytes/:size` - Deterministic generated bytes with `HEAD` and `Range` support.
- `/meta/:size` - JSON metadata for `/bytes/:size`.

The intended deployed hostname is `https://gtr-cf-test-origin.677472.xyz`.
